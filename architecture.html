Экспорт данных в Excel — проект «Электронный деканат»

1. Задача

Реализовать выгрузку ведомостей, списков студентов и отчётов в формате Excel для сотрудников деканата.

2. Проблема

Данные хранились в нескольких таблицах, требовали объединения, форматирования и быстрой генерации без нагрузки на сервер.

3. Архитектурное решение

  • Создан отдельный модуль ExportService для формирования Excel.
  • Использован слой DataCollector для объединения данных из разных таблиц.
  • Введён DTO-слой для стандартизации структуры выгружаемых данных.
  • Генерация Excel вынесена в асинхронный процесс.

4. Поток данных

Пользователь → Контроллер → DataCollector → ExportService → Excel-файл

5. Ключевой фрагмент кода


public FileResult ExportToExcel()
{
    var data = _dataCollector.GetStudentsReport();
    var file = _excelService.GenerateExcel(data);
    return File(file, "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet", "report.xlsx");
}

6. Результат

  • Время генерации отчёта — менее 1 секунды.
  • Файл содержит форматирование, стили и автоширину колонок.
  • Сотрудники деканата могут выгружать отчёты в один клик.

7. Возможные улучшения

  • Добавить шаблоны Excel.
  • Реализовать массовую выгрузку нескольких отчётов в ZIP.

Генерация расписания — проект «Железнодорожный вокзал»

1. Задача

Реализовать автоматическую генерацию расписания поездов на основе данных о маршрутах, времени отправления и прибытия. Система должна формировать таблицу расписания для отображения на сайте и выгрузки в PDF.

2. Проблема

Данные поступали из разных источников — ручные записи, API перевозчика, локальные таблицы. Требовалось объединить их в единую структуру и обеспечить актуализацию расписания без ручного вмешательства.

3. Архитектурное решение

  • Создан модуль ScheduleGenerator для формирования расписания на основе входных данных.
  • Использован слой DataIntegrator для объединения данных из API и локальных таблиц.
  • Добавлен CacheLayer для ускорения повторных запросов и снижения нагрузки на сервер.
  • Реализована автоматическая актуализация расписания каждые 24 часа через Cron‑задачу.

4. Поток данных

API перевозчика → DataIntegrator → ScheduleGenerator → CacheLayer → HTML/PDF‑расписание

5. Ключевой фрагмент кода

public class ScheduleGenerator {
    public List Generate() {
        var data = _dataIntegrator.GetTrainData();
        var schedule = data.Select(d => new TrainSchedule {
            TrainNumber = d.Number,
            Departure = d.DepartureTime,
            Arrival = d.ArrivalTime,
            Route = d.Route
        }).ToList();
        _cacheLayer.Save(schedule);
        return schedule;
    }
}

6. Результат

  • Расписание обновляется автоматически без участия администратора.
  • Время генерации — менее 2 секунд.
  • Данные синхронизируются с API перевозчика.
  • Пользователи видят актуальное расписание на сайте и могут скачать PDF‑версию.

7. Возможные улучшения

  • Добавить визуализацию маршрутов на карте.
  • Реализовать фильтрацию по станции и времени отправления.
  • Интегрировать уведомления об изменениях расписания.
